# Attachment policy

Status: accepted. This decision supersedes the archived sixteen-mebibyte prototype.

## Binary boundary

An attachment may contain at most 8,388,608 bytes (eight mebibytes). Exactly that
many bytes are accepted; 8,388,609 are rejected. Decimal megabytes are not used.
The Python authority is `admit_blob`. Browser validation is advisory, not a
substitute for the server. The mobile client's seven-mebibyte copy is outdated.

## Entry points

[Gateway](../src/gateway.py) calls the storage rule through an import alias.
[PHP policy](../clients/api/UploadPolicy.php) independently enforces the limit.
[Web control](../clients/web/upload.ts) and [mobile control](../clients/mobile/upload.ts)
are client copies. Changing the policy requires inspecting all four entrypoints.
[Boundary test](../tests/test_delivery.py) is static test evidence, not a test run.
