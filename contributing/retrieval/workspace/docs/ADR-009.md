# Delivery replay policy

Status: accepted. A courier may resend an envelope after losing an acknowledgement.
The second arrival must not apply the work again. The receipt set is updated only
for the first arrival. `settle_once` is the authority, reached through `receive`.
This is unrelated to retrying image decoding or refreshing a contact address.

[Receiver](../src/delivery.py) and [regression](../tests/test_delivery.py) implement
and exercise the policy. The example below is deliberately not a real reference.
