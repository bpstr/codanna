# Coverage of the original follow-up scenarios

The investigation's 21 follow-ups mix concrete missing behavior with broader
qualification plans. This crosswalk identifies the implemented portions and the
remaining work. It does not turn a partial implementation into a completed
qualification. The original [checklist](CHECKLIST.md) retains the proposed scope;
the [additional checklist](ADDITIONAL-CHECKLIST.md) and its
[result artifact](additional-results.json) contain the named tests and their
measured outcomes. All 101 implementation fixtures have recorded passing results.
Broader qualifications remain open where the table identifies additional scope.

`ADR` identifiers refer to the original 62 cases. `ADX` identifiers refer to the
101 implementation fixtures: 99 new tests and two revised existing Python units.
The revised entries retain their former test names and explain the change without
claiming a historical baseline result. The manifests keep complete test names,
source paths, layers, and baseline status.
