# F10: Freeze and execute a synthetic retrieval holdout

Status: Complete. Both manifest validation and all eight executable oracle cases passed; independent quality review approved the final harness. Repository and GitHub gate results are recorded on the pull request.

The `f10-v1` corpus contains exactly three synthetic source files: `account.ts`, `reference.ts` and `policy.md`. The source-only corpus SHA-256 is `eb0a1591ac4716ee25c7b13f6ddca1ffa29c2505b5f9a10ecd2a0521e9259a3e`. `tests/fixtures/retrieval_findings/f10/manifest.json` records each source hash, the separate oracle hash and the index allowlist. The corpus identity hashes sorted `relative_path + NUL + source_sha256 + newline` records. Files are hashed as raw bytes.

Independent source review established the expected identities and graph before the harness was implemented: both `accountWeekStart` definitions are discoverable, the account scope excludes the reference, and `displayWeek` calls only the account definition. The reference has no callers. Review strengthened the original count-only oracle and added a positive document control alongside its negative.

Eight frozen cases cover exact and scoped symbol discovery, unique callers, the namesake's empty caller set, the exact callee, positive/negative literal document retrieval and an absent symbol. `tests/frozen_retrieval_holdout.rs` checks hashes and file inventory, creates scratch indexes with embeddings disabled, closes them, and exercises each oracle through CLI JSON. It checks exact result identities, duplicate counts and exit codes. The document cases also assert literal mode and support-not-assessed metadata. Only allowlisted source files enter the scratch corpus; the oracle contains the negative sentinel and must never be indexed.

Run the local fixture without inherited provider credentials:

```bash
env -i HOME="$HOME" PATH="$PATH" TMPDIR="${TMPDIR:-/tmp}" cargo test --test frozen_retrieval_holdout -- --nocapture
```

Treat `f10-v1` as immutable reviewed evidence. Any change to a source or expected result requires a new corpus version, explicit hash updates and independent review; never rewrite the oracle from observed program output. Preserve earlier failures. The manifest test rejects source/oracle hash drift, unexpected files and allowlist changes.

This tiny synthetic corpus supports regression assertions only. It does not measure provider quality, broad retrieval accuracy, scaling or latency percentiles. No production ranking change is part of this finding. Automated execution uses local data with no providers, credentials, subscription proxies, automatic fixture recording or active-corpus mutation.
