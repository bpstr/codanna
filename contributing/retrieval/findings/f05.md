# F05: Track phrase and authority ranking

Status: Implemented and exercised with deterministic local fixtures.

The reduced synthetic sources and explicit oracle in `tests/fixtures/retrieval_findings/f05/cases.json` now run through the production document index. A caller may supply exact indexed source paths through MCP `search_documents`; those paths receive a deterministic tiebreak after distinct query-term coverage. The default remains unchanged, authority is never inferred from document text, and matching historical sources remain accessible.

Structured retrieval metadata records whether the prior was applied, its `caller_supplied_source_paths_v1` basis and the source count. Candidate output states that the prior is caller supplied and unverified. Empty source paths fail validation.

The F05 regression verifies an authority-based lexical tie, repeatable ordering, the canonical first-place result, continued access to the historical decoy, applied diagnostics, the omitted-default negative control and invalid empty input. Existing symbol-ranking regressions already exercise broad multi-term calendar-settings queries using the production distinct-term-coverage ranker.

The focused regression runs solely on prepared local text. Provider request count is zero; no credentials, subscription proxy, automatic recording, private source or original report are used.

Repository-wide gate results are recorded in PR77 before merge.
