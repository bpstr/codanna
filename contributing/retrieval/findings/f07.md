# F07: Track interface dispatch and protocol type uses

Status: Implemented and exercised with deterministic local fixtures.

The reduced synthetic sources and explicit oracle in `tests/fixtures/retrieval_findings/f07/cases.json` now run through the production parser, resolver and persistent relationship index. Go interface-field calls retain the interface method as a source-grounded reference and expose each structurally valid implementation as `DispatchCandidate`. These edges are distinct from definite runtime `Calls`.

Python `typing.cast` type arguments now produce `Uses` edges. Imported aliases resolve to their declared protocol, while a same-named function parameter suppresses the imported type edge.

The F07 regression verifies both Go implementation candidates, interface-call source metadata, the absence of concrete call edges, imported protocol alias resolution, parameter shadowing and the absence of cast-type call edges. It also changes one Go method signature and verifies that the stale dispatch candidate is removed.

The focused regression uses only prepared local source. Provider request count is zero; no credentials, subscription proxy, automatic recording, private source or original report are used.
