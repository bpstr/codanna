## Deployment and API migration

### Network authentication and authorization

Stdio keeps the local-process trust boundary and needs no network token.
HTTP and HTTPS require operator credentials. Plain HTTP binds only to loopback;
non-loopback service uses HTTPS. Only `/health` is intentionally public.

For one fully trusted operator, `CODANNA_MCP_TOKEN` accepts a random 32–512-character
bearer credential. Clients send `Authorization: Bearer <secret>`. This mode gives
that operator read and reindex rights over the configured installation. Do not
share that credential with clients that should be read-only.

For distinct clients/subjects, set `CODANNA_MCP_AUTH_FILE` to an operator-owned JSON
file outside repository-controlled configuration. This setting takes precedence
over the legacy token variable. Its structure is:

```json
{
  "principals": [
    {
      "subject": "read-only-client",
      "token_sha256": "<64 hexadecimal characters: SHA-256 of the secret token>",
      "workspaces": ["/absolute/path/to/workspace"],
      "scopes": ["read"]
    }
  ]
}
```

The hash above is a format placeholder, not a usable credential. Generate a strong
random bearer token privately, store it in the client's secret settings, and put
its SHA-256 hash in the policy. Do not commit or print the secret. Add `reindex`
to a principal's scopes only when that principal may mutate the index. Every
principal needs `read`; subjects and credential hashes must be unique. Keep the
policy writable only by the operator and restart the server after policy changes.

One process serves one whole workspace. Workspace ACLs require exact canonical
workspace identity, not merely an ancestor prefix. Policy mode validates existing
index provenance and rejects foreign-workspace rows. Use separate processes and
indexes for different workspaces or mutually untrusted tenants. This is not
per-file visibility, an OAuth authorization server, delegated tokens, or a
cryptographic sandbox against another process with the same filesystem privileges.
OAuth-only clients need an external compatible adapter; the previous placeholder
OAuth endpoints must not be restored.

Admission limits include a 1 MiB JSON request body, 64 concurrent admitted
requests, serialized initialization admission and 1,024 tracked sessions. Sessions
are bound to their subject and expire after one hour of inactivity; transport
cleanup checks periodically. Clients must reinitialize after expiry and handle
busy responses without treating them as successful work.

Force-reindex accepts at most 64 submitted roots and validates up to 100,000
visited entries, 10,000 unique source files, 128 MiB total captured source and
32 MiB per source file. Overlapping roots do not duplicate source files. A budget
or containment failure happens before index mutation. The captured bytes, not a
second filesystem walk, feed the pipeline. These are explicit server limits, not
an assurance that a same-privilege hostile local process cannot alter the host.

### Persistence and server lifecycle

Stop older servers before upgrading and preserve an index backup. The serve lock
file remains on disk intentionally; releasing the OS-held lock does not unlink
it. Never remove an active lock file to start another owner.

Semantic persistence now supports format version 2: immutable checkpoints plus
bounded ID deltas/tombstones, referenced by an atomically published manifest.
Legacy version-1 data remains readable and is migrated when a changed save writes
a new generation. **Older binaries must not write the new format.** For rollback,
restore an appropriate backup or explicitly rebuild into a separate index; do not
edit version numbers or discard referenced artifacts to force a load.

Dirty saves normally write only deltas. At most 4,096 dirty IDs fit the delta
path; larger updates or periodic compaction (up to 64 referenced deltas) create a
new checkpoint. Unchanged saves to the same destination do not rewrite vectors.
Reader/writer filesystem locks protect loading and checkpoint garbage collection;
manifest comparison rejects competing writers. Prepared-save revision checks
prevent an older snapshot from erasing a newer commit. Referenced corrupt or
missing artifacts cause errors; unreferenced interrupted writes are not adopted.

File synchronization and, on Unix, directory synchronization support durable
publication. The deterministic interruption/corruption/conflict tests do not
certify arbitrary hardware power loss, network filesystems, or every Windows
filesystem implementation. Preserve corrupt state for diagnosis instead of
turning load failures into an empty index. Registry saving is atomic, but this
batch does not add multi-process registry transactions.

### Rust, query, plugin and example compatibility

- Root `StorageError`/`StorageResult` name the active storage API. Old types remain
  available as `LegacyStorageError`/`LegacyStorageResult` and under `error`.
- `CompactSymbol.file_id` is `u32`; do not persist its in-memory field offsets as
  an undocumented binary format.
- `Chunker::chunk` accepts `ValidatedChunkingConfig`. Merge external collection
  overrides, then convert with `try_from`; the contract remains `overlap < min < max`.
- Behavior/context construction, discovery and relationship writes are fallible.
  Callers must propagate failures rather than substitute another language, empty
  inventory or successful durability receipt. `WriteStage::write` acceptance is
  not durability until its commit/flush succeeds.
- TypeScript resolution instances capture an explicit `.codanna` directory.
  Separate workspaces must use separate instances/absolute roots. Clones of one
  instance share its own TTL cache; unrelated workspaces do not share alias rules.
- Search limits are 1–1,000; impact depth is 1–10. Network graph traversal bounds
  nodes/edges and reports exceeded budgets explicitly. Legacy complete enumeration
  is not silently restricted to 1,000 results. Narrow requests that exceed limits.
- The mutation lane releases facade guards during expensive work and serializes
  mutations per facade. It is not a transaction spanning Tantivy, semantic data
  and document state. Errors may follow partial committed work; they remain errors.
- Plugin clones containing symlinks/special entries now fail closed, including
  internal symlinks. Ship regular files. Visualization preflight requires tested
  Node 22.16.0 and Codanna 0.16.0 release minima; saved dumps only require Node.
- Retrieve JSON now agrees with its process exit codes: not found 3, invalid query
  1, projection errors 2. MCP retains its separate established 1/2 vocabulary.
